原因:
1. base transformer的llm受注意力机制的缺陷影响存在多级目标冲突;
2. 存在临端任务优先;
3. 单次推理运行的内部结构无法生成有效差异性回路并发运行

用于:
类差异化输出目的的任务

原理:
1. 门控回溯
2. 相似结果可坍缩
3. 近端注意力选择转移


模式:
1. 设置N道独立判断门，并至少设定一道差异性判断门控
2. 初始化推理参数
3. 设置优化器参数
4. 设置跳出机制


main:
执行器读取决策记录-->向执行器输入推理参数-输出->推理结果-->[门控组]-全量通过->执行推理
                            ↑                          |
                            |_____若存在否定____________|

当main结束时
优化器读取优化参数-->优化器读取当论次决策记录-->记录当前推理参数信息-->更新推理参数|(也可设置门控循环)


任意门控过程:
执行器理结果-->接入A门控判断-->门控推理-->决策信号-->记录门控推理
                                                    |
    |-----------------------------------------------↓
    ↓
执行器理结果-->接入B门控判断-->门控推理-->决策信号-->记录门控推理
...

or
              |---接入A门控判断-->门控推理-->决策信号-->记录门控推理
执行器理结果---|---接入B门控判断-->门控推理-->决策信号-->记录门控推理
              |---....


上面的一次执行推理+更新推理参数为一次模式执行


细节:
门控组的参数在该模式中不参与不更新;
优化参数在该模式中不参与不更新;



案例:
- 设置差异性判断门控: “是否和之前的所有结果显著差距？”
- 设置回归性判断门控: "是否偏离原本目标?"->设置目标
- 设置反馈性判断门控: "是否忽略了用户的反馈"->可选
- 初始化自动反馈参数: "重写"
- 设置优化器参数: "分析 xx 轨迹，分析为什么这次运行中的自动反馈参数经常失效？并执行优化:将“xxx”改写为xxx"
- 当门控反馈否定次数超过5次,结束循环,并根据最后一次的推理结果进行一次实际推理;
补充:所有门控的精度设置为高要求

具体
1. 设定目标: 优化头脑风暴能力
2. 执行器生成了 提示词A

10. 计算回归性判断门控: 不通过;
11. 执行器(自然)得到记录

15. 记录任务结果
