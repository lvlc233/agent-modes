
门控机制,简单来说,就是系统在计算过程中,存在一组 **在输出前** 的 **用于判断** 的 内部判定机制;使计算结果能够产生 **回流** 的设计。

对于门控来说，需要明确不同门控所对应的处理的 **判断对象**和 **路由去向**

## 补充:
- 该机制不预设反馈必然达成优化、求解。
- 从机制上来说，经典ReAct模式设计就是设定一个极简的含门控循环;
